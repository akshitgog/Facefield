# FaceField Application Instructions

Welcome to the FaceField submission!

> [!WARNING]
> **Judges Testing Disclaimer (MVP Notice):**
> 1. To install, open the `FaceField_App.apk` file included in this folder via your Android **File Manager**.
> 2. Close the app, then go back to the File Manager and install it **one more time** (click "Update").
> 3. Open the app and fill in your signup details.
> 4. When clicking to scan your face, the app may close/crash once. This is just a one-time MVP memory allocation error!
> 5. **Simply reopen the app and signup again.** From that point forward, the entire pipeline is buttery smooth and extremely stable!

## Architecture Details
- **AWS Integration Details**: Please see `AWS_INTEGRATION.md` in this directory for details on our cloud sync and purge mechanism.
- **Active source code**: Build the React Native / Kotlin app from the root `client/` and `android/` directories. `Source_Code/` is an older snapshot, not the active CameraX app.
